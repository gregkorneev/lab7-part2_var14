## 1. Выбор метода решения
Выбран метод **динамического программирования O(n²)**.
Он подходит, потому что задача обладает свойствами:
- оптимальной подструктуры: решение LIS на `i` зависит от предыдущих `j<i`;
- перекрывающихся подзадач.

**Почему не уменьшение размера:**
Жадный метод `n log n` сложнее для реализации и хуже подходит для учебной демонстрации.

**Почему не декомпозиция:**
Подпоследовательность может пересекать любую границу, поэтому разбиение массива не даёт преимущества.

---

## 2. Реализация
Реализованы два алгоритма:
- основной — ДП O(n²)
- наивный — полный перебор (экспонента), для маленьких n

Код находится в `src/main.cpp`.
